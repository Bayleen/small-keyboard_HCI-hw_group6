# Design 1 — StarFlick V1 Updated (First Refinement)

**Previously:** `prototype-v3/`

This iteration keeps the grouped-flick concept while improving error prevention and legibility.

### Refinements

- Finger-aware floating selection guide.
- More forgiving letter-selection zones.
- A deliberate downward/outward cancel gesture to reduce accidental cancellation.
- Clearer delete behavior and cursor editing.

### Testing role

Compare with [V1](../prototype-v1/) to evaluate the benefit of feedback and cancellation refinements. The team observed that experienced users might benefit from memorized flick mappings, which remains a qualitative observation.

Calibrate on the actual device via `calibrate.html`; launch `index.html`.
